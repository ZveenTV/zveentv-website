2. Hosting über Netlify

Diese Website wird über Netlify bereitgestellt. Beim Aufruf der Website können technisch erforderliche Verbindungsdaten wie IP-Adresse, Zeitpunkt, aufgerufene Ressource, Browser- und Geräteinformationen in Server-Logs verarbeitet werden. Die Verarbeitung dient der sicheren und zuverlässigen Bereitstellung der Website.

3. Twitch

Auf dieser Website werden Inhalte von Twitch eingebunden. Der Twitch-Player wird auf der Startseite erst geladen, wenn der Kanal live ist. Clip-Player werden erst nach einem Klick auf einen Clip geladen. Beim Laden solcher Inhalte wird eine Verbindung zu Twitch hergestellt; dabei können insbesondere IP-Adresse, Geräteinformationen und ggf. Cookies bzw. vergleichbare Technologien durch Twitch verarbeitet werden.

4. Twitch-API

Zur Anzeige von Live-Status, Streamtitel, Kategorie, Zuschauerzahl sowie Clip-Informationen ruft der Server öffentliche Twitch-Daten über die Twitch-API ab. Dabei werden keine Twitch-Zugangsdaten von Website-Besuchern abgefragt.

5. Google Fonts

Zur einheitlichen Darstellung von Schriftarten werden Google Fonts geladen. Beim Abruf kann eine Verbindung zu Servern von Google hergestellt und insbesondere die IP-Adresse verarbeitet werden.

Die Website verlinkt unter anderem auf Twitch, Discord, YouTube, Instagram und TikTok. Erst beim Öffnen eines solchen Links gelten die Datenschutzbestimmungen des jeweiligen Anbieters.
